# 📱 FocusDock - ระบบแท่นวางมือถืออัจฉริยะ & บันทึกการพักมือถือ (Mobile-First Web App)

เว็บแอปพลิเคชันดีไซน์แบบ **Mobile-First มินิมอล อ่านง่าย สบายตา** ที่ออกแบบมาเพื่อทำงานควบคู่กับแท่นวางมือถืออัจฉริยะ (IoT Hardware) รับส่งข้อมูลผ่าน **Firebase Realtime Database**

---

## 🌟 ฟังก์ชันหลักที่ครบถ้วนตามความต้องการ

1. **📱 ใช้งานผ่านมือถือเป็นหลัก (Mobile-First & PWA)**
   - ออกแบบสำหรับหน้าจอมือถือโดยเฉพาะ พร้อมรองรับ **Add to Home Screen (PWA)** ให้เปิดใช้งานได้เหมือนแอปแท้
   - มีเมนูแถบล่าง (Bottom Navigation Bar 4 แท็บ) ใช้งานง่ายด้วยนิ้วโป้ง
   - บนหน้าจอคอมพิวเตอร์ มีกรอบจำลองมือถือสุดมินิมอล พร้อมปุ่มสลับเป็นโหมดเต็มจอได้

2. **🟢 ตรวจจับและแสดงสถานะการหยิบจับมือถือแบบ Real-time**
   - **เมื่อวางมือถือบนแท่น**: แสดงสถานะสีเขียวผ่อนคลาย *"วางอยู่บนแท่นพัก • พร้อมมีสมาธิ"*
   - **เมื่อหยิบมือถือขึ้นมา**: แสดงสถานะสีส้มอมพีชพร้อมเวลานับสด *"⚠️ กำลังหยิบใช้งาน: 01:25"* (นับวินาทีแบบ Live ทันที)
   - สรุปยอดรวมประจำวัน: *"หยิบมือถือไปแล้ว X ครั้ง | รวมเวลา X นาที"*

3. **⏱️ บันทึกประวัติและเวลาการหยิบจับอย่างละเอียด**
   - แสดงเวลาจริง (เช่น `14:20:15 - 14:23:45`)
   - แสดงระยะเวลาที่จับในแต่ละครั้ง (เช่น `3 นาที 30 วินาที`)
   - ระบุโหมดขณะเกิดการหยิบจับ (หยิบขณะอ่านหนังสือ / หยิบขณะพักมือถือ)
   - ฟิลเตอร์ดูย้อนหลังได้: ทั้งหมด, วันนี้, เมื่อวาน, หรือแยกตามโหมด

4. **📊 สถิติย้อนหลัง 1 สัปดาห์ (Weekly Analytics)**
   - **KPI การ์ด 3 ช่อง**:
     1. จำนวนครั้งที่หยิบจับใน 1 สัปดาห์ (เช่น `38 ครั้ง`)
     2. เวลาเฉลี่ยในการจับแต่ละครั้ง (เช่น `3.2 นาที/ครั้ง`)
     3. เวลารวมทั้งหมดที่หยิบมือถือในสัปดาห์ (เช่น `2 ชม. 02 นาที`)
   - **กราฟแท่ง 7 วัน (จันทร์ - อาทิตย์)**:
     - กราฟแท่ง Interactive สลับดูได้ทั้ง "จำนวนครั้ง" และ "เวลารวม"
     - แตะที่แท่งกราฟของแต่ละวันเพื่อดูสรุปสถิติประจำวันนั้นๆ ได้ทันที

5. **⚙️ รองรับ 2 โหมดการทำงานเหมือนตัวเครื่อง & ตั้งค่าได้ผ่านเว็บ**
   - **📖 โหมดอ่านหนังสือ (Study Mode)**:
     - ตั้งเวลาอ่านหนังสือ (Study Time) เช่น 25, 45, 50 นาที
     - ตั้งเวลาพักสายตา (Break Time) เช่น 5, 10 นาที
     - รองรับ Pomodoro Cycle (รอบที่ 1-4) พร้อมวงแหวนนับถอยหลัง SVG นุ่มนวล
   - **📵 โหมดพักจากมือถือ (Digital Detox Mode)**:
     - ตั้งเวลาที่ไม่แตะมือถือ เช่น 30, 45, 60, 120 นาที
     - วงแหวนนับถอยหลัง พร้อมแจ้งเตือนเมื่อสำเร็จภารกิจ

6. **🔘 ควบคุมเริ่ม/พัก/หยุดได้ทั้ง 2 ทาง (Web & Physical Device Button)**
   - กดปุ่ม **เริ่ม / พัก / รีเซ็ต** ผ่านหน้าเว็บได้
   - กดปุ่มจริง (Push Button) ที่ตัวเครื่อง ESP32 ได้ โดยเว็บจะอัปเดตและเริ่มจับเวลาตามทันที
   - มี **แผงจำลองเครื่องจริง (Hardware Test Panel)** บนหน้าเว็บ เพื่อให้ทดสอบหยิบมือถือ/วางมือถือ หรือกดปุ่มเครื่องได้ทันทีแม้ยังไม่ได้ต่อฮาร์ดแวร์จริง!

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดเซิร์ฟเวอร์บนเครื่อง
รันคำสั่ง:
```bash
node server.js
```
เปิดบราวเซอร์ไปที่: **`http://localhost:3000`**

### 2. วิธีเปิดบนมือถือจริงผ่าน Wi-Fi เดียวกัน
1. เปิด Command Prompt หรือ PowerShell แล้วพิมพ์ `ipconfig` เพื่อดู IPv4 Address (เช่น `192.168.1.50`)
2. เปิดเบราว์เซอร์บนมือถือ (Safari หรือ Chrome) แล้วเข้าไปที่:
   ```
   http://192.168.1.50:3000
   ```
3. กดปุ่ม **Share > Add to Home Screen** (บน iOS) หรือ **Install App** (บน Android) เพื่อใช้งานแบบเต็มหน้าจอ
